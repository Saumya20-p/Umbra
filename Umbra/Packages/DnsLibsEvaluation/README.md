# DnsLibs experimental integration

This package uses local `Artifacts/AGDnsProxy-2.8.45-umbra-transport1.xcframework`, built from DnsLibs commit `e0654ab8c53109c6cca7a706b6c1166f96f0a3c4` plus the additive transport patch. It includes iPhone arm64 and Simulator arm64/x86_64. [PATCH.md](PATCH.md) describes the change; [BUILD.md](BUILD.md), `NativeBuild.json`, `baseline-macos.lock` and `ArtifactHashes.json` record build inputs, resolved package revisions and artifact hashes. It is an experimental dependency, not approved for distribution.

Rollback baseline: official `https://github.com/AdguardTeam/DnsLibs/releases/download/v2.8.45@swift-5/AGDnsProxy-apple-2.8.45.zip`, SHA256 `f9d0495427909b19376bfe6fead93af6c9acc401880fddf29de3dd89244c552b`, manifest commit `5570e10e4883f9fe770a291b4025449127185f88`. Reverting requires restoring the old `messageHandler:` initializer and nil info together with that binary. The official archive remains in the machine's SwiftPM artifact cache; the pinned source baseline is unchanged.

The app, experimental extension and unit-test target link this dependency. The app's dependency is required to embed the dynamic framework in `Umbra.app/Frameworks`, where the extension's runpath can load it. It is not approved for production distribution and grants no permission to use AdGuard's resolver service. Tests use synthetic DNS, local rules, a failing loopback TLS upstream and a fixed loopback UDP reply fixture; they do not contact a public resolver or modify DNS/VPN settings.

The official archive includes the Apache 2.0 engine license, but lacks transitive notices and a publisher SBOM. `ThirdPartyNotices.txt` provides a source-based dependency notice inventory, with provenance in `LicenseSources.json` and `LicenseAudit.md`. Preserve it in the extension bundle. Final distribution review remains required, including legacy acknowledgment/advertising terms. Version 2.10.2 is newer; its public source uses an Artifact Keeper URL variable rather than a publicly resolved Apple binary manifest. Do not silently upgrade or substitute an unverified binary.

The patched listener exposes UDP/TCP metadata, which the provider passes to `AGDnsMessageInfo` with transparent processing disabled. Loopback regression tests verify UDP limits/TC, full TCP replies and both cache orders. Five native listener validation tests and all 62 Simulator tests pass. This fixes a demonstrated adapter defect; live tunnel truncation/retry acceptance remains pending on the updated build. The previous device report failed UDP advertised-size acceptance.

See `Research/12-Local-Tunnel-Feasibility.md` at the workspace root for feasibility limits. No resolver, list, routing, counter, recovery policy or finished UI change is part of this repair.
